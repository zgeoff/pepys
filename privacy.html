Privacy policy

Last updated 4 November 2026.

pepys is self-hosted software. Each deployment is run by one owner, for that owner alone, using an OAuth client the owner registers in their own Google Cloud project. The pepys project operates no service and receives no user data.

Data a deployment accesses

With the owner's consent, a deployment reads the owner's Gmail messages and their metadata, such as headers, labels and history, through the Gmail API. It reads only; it never sends, changes or deletes mail.

How the data is used and stored

  • Data is used only to give the owner a searchable, linked record of their own data.
  • Data is stored only on hosts the owner controls.
  • Data is not sold, not shared with third parties except the AI model provider the owner configures to label and link messages, and not used to train general AI models.
  • The owner can revoke access at any time at myaccount.google.com/permissions, and can delete stored data from their deployment.

pepys's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
