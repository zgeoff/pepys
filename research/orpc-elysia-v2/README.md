# Spike: ORPC on Elysia v2

The API runs Elysia v2 with oRPC for typed routes. Elysia v2 is at release candidate and oRPC v2 is
in beta, so this spike mounts oRPC on Elysia v2, for the API design.

## Question

Does oRPC's Elysia adapter work with Elysia v2, and does it need oRPC v1 or v2?

## Answer

- The spike has not run, so it holds no verdict and no numbers.

The API design holds no recommendation from this spike until it runs.
